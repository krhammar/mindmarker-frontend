## Prerequisites:
Before getting started, install:
- Python
- Github Desktop
- Visual Studio Code (recommended)

## Setup Instructions

## 1. Clone repository
Open github desktop and clone the repository to your computer
## 2. Open the project
Open the project folder in VS Code, then open Terminal using **Terminal -> New Terminal**
## 3. Create a virtual environment
Necessary for python programs to work.
On windows, run these commands (If you aren't on windows, good luck):
''' python -m venv .venv
venv\Scripts\Activate.ps1 '''
## 4. Install Dependencies
With virtual environment activated run:
''' python -m pip install -r requirements.txt '''
## 5. Run the app
''' python -m streamlit run app.py '''

## Updating the Project
Use github desktop to pull latest changes before starting work
Guys please commit regularly

If requirements.txt has changed, activate the virtual environment and run
''' python -m pip install -r requirements.txt '''
